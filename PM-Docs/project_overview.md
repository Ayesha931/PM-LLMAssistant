# Project Overview: HealthLingo - App Redesign

## Background
HealthLingo aims to provide accessible and easy-to-understand healthcare information for underserved communities. With the rise of smartphone usage, our app redesign project focuses on improving accessibility and engagement.

## Project Goals
- Enhance accessibility for users with low literacy
- Increase daily active users by 25%
- Improve health literacy in underserved communities

## Timeline
The redesign project will run for a total of 6 weeks.
